# Contributing to BASICALLY

Welcome! BASICALLY is an open-source project dedicated to building a
modern BASIC language and, eventually, a lightweight 2D game engine.

Whether you're fixing a typo, improving the interpreter, designing
language features, or building development tools, contributions are welcome.

## Our Philosophy

**Take it. Build with it. Make something cool. Share the good stuff.**

BASICALLY is released under the MIT License. You're free to use it,
modify it, fork it, and build your own projects with it.

If you develop an improvement that could benefit BASICALLY itself,
we encourage you to contribute it back!

You don't owe us your games, your ideas, or every line of code you write.
But if you build a better BASICALLY, we'd love for the main project
to benefit from your work.

Let's build something cool together.

## What Can I Contribute?

Almost anything that improves the project!

- Bug fixes
- New language features
- Interpreter improvements
- Performance optimizations
- Documentation
- Examples and tutorials
- Game engine features
- Graphics and audio tools
- Testing and error reports
- Ideas for improving BASICALLY

## How to Contribute

1. Fork the repository on GitHub.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your work with a descriptive commit message.
5. Open a pull request targeting the `main` branch.

If your contribution is a major language feature or architectural
change, consider opening an issue first so we can discuss the design.

## Development Guidelines

- Keep changes focused and understandable.
- Include tests for new functionality whenever practical.
- Update documentation when behavior or syntax changes.
- Provide examples for new language features when possible.
- Be respectful of other contributors and their ideas.

BASICALLY is under active development, so some design decisions may
change as the language evolves.

## No Contribution Required

You are not required to contribute your own projects or modifications
back to BASICALLY simply because you use it.

The MIT License governs your rights and obligations.

Contributing improvements is encouraged because we want BASICALLY
to grow alongside the people who use it.

## Thank You

Every contribution helps BASICALLY become a better language and a
better tool for making games.

Take it, build something cool, and bring the good stuff home!
